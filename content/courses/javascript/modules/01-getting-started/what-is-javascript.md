## Welcome

JavaScript is the language of the browser — and a lot of servers too. In this course you learn by **writing real code**, running it, and matching expected output.

### How lessons work

1. Read the short explanation on the left.
2. Edit the starter code on the right.
3. Click **Run Code**.
4. When your output matches the expected result, the lesson is marked complete.

### Challenge

Create a variable named `message` with the value `Hello, Education!`, then keep the `console.log` line so the program prints that message.
