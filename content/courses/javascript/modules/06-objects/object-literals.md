## Named bags of data

Objects group related values under keys:

```js
const user = {
  name: "Riley",
  role: "dev",
}
```

Arrays are ordered lists; objects are labeled fields. You’ll use both constantly.

### Challenge

Create `user` with `name` and `role` as specified.
